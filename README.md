# PNGTuber

Лёгкое приложение для PNG-тюберов: аватар меняет картинку, когда вы говорите, моргает и подпрыгивает в такт речи. Работает на Python + pywebview (Qt), интерфейс — обычный HTML. Микрофон читает сам Python (sounddevice/PortAudio), поэтому приложению не нужно браузерное разрешение на микрофон.

## Возможности

- Четыре состояния: молчит, говорит, моргает молча, моргает во время речи (моргание необязательно).
- Двухпороговый аудиорегистр (как в Veadotube mini) для четкой реакции без дрожания рта и поддержка сверхмалых задержек (до 0 мс).
- Фоновый режим для OBS Studio: окно не засыпает и не исчезает при сворачивании.
- Загрузка картинок кликом или перетаскиванием на слот, миниатюры в панели.
- Выбор микрофона, усиление звука (Gain), фильтр щелчков (атака).
- Палитра пресетов хромакея, размер аватара, отражение по горизонтали.
- Сохранение и загрузка сцены (`.pngtuber`) — настройки и картинки в одном файле.
- Настройки и загруженные картинки запоминаются между запусками (хранятся в конфиг-каталоге: `~/.config/PNGTuber`, `%APPDATA%\PNGTuber`, `~/Library/Application Support/PNGTuber`).

## Использование

1. Скачайте архив для своей системы в разделе Releases, распакуйте его целиком в папку и запустите `PNGTuber`.
2. Откроется окно с панелью настроек (клавиша `S` показывает и скрывает её).
3. Вкладка «Аватар» — загрузите свои картинки.
4. Вкладка «Звук» — выберите микрофон и настройте чувствительность (зелёный маркер — открытие рта, оранжевый — закрытие).
5. Сохраните сцену, чтобы не загружать картинки заново.

## OBS Studio

1. Источник «Захват окна» → окно PNGTuber.
2. Фильтры → «Хромакей». Фон по умолчанию зелёный (`#00ff00`); цвет меняется на вкладке «Экран».
3. Вместо хромакея можно запустить с флагом `--transparent` (прозрачное окно). На части систем Linux из-за этого появляются артефакты отрисовки, поэтому по умолчанию он выключен.

## Запуск из исходников

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

На Linux для микрофона нужна системная библиотека PortAudio (`sudo apt install libportaudio2`).

## Структура

```
main.py          окно (pywebview/Qt), хранение настроек и картинок, сохранение/загрузка сцен
web/index.html   разметка
web/style.css    оформление
web/app.js       логика: аудио, состояния аватара, настройки
```

Сборка исполняемого файла выполняется через GitHub Actions (`.github/workflows/release.yml`) при пуше тега `v*`.
