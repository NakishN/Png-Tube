# PNGTuber

Легковесное и оптимизированное приложение для PNG-тюберов. Разработано на базе Rust и Wry, использует системный webview, что обеспечивает минимальное потребление процессора и оперативной памяти по сравнению с аналогами на игровых движках.

## Особенности

- Низкое потребление системных ресурсов.
- Кроссплатформенность (Windows, macOS, Linux).
- Настройка порога срабатывания микрофона.
- Поддержка пользовательских изображений (состояния покоя и разговора).
- Настраиваемый цвет фона (для интеграции через хромакей).

## Инструкция по использованию

1. Загрузите исполняемый файл для вашей операционной системы из раздела Releases.
2. Поместите ваши изображения в одну директорию с исполняемым файлом. Файлы должны иметь строго следующие названия:
   - `idle.png` — изображение при отсутствии звука.
   - `speaking.png` — изображение во время разговора.
3. Запустите приложение. При отсутствии файлов в папке будут использованы изображения по умолчанию, встроенные в программу.
4. Внутри программы нажмите клавишу `S`, чтобы открыть или скрыть меню настроек.
5. Нажмите кнопку "Включить микрофон" в настройках и разрешите доступ.

## Интеграция с OBS Studio

1. Запустите PNGTuber.
2. В OBS Studio добавьте новый источник "Захват окна" (Window Capture).
3. Выберите окно приложения PNGTuber.
4. Нажмите правой кнопкой мыши по созданному источнику, выберите "Фильтры".
5. Добавьте фильтр "Хромакей" (Chroma Key). Базовый цвет фона в программе — зеленый (#00ff00), он будет вырезан автоматически. При необходимости цвет можно изменить в настройках программы.

## Сборка из исходного кода

Для самостоятельной сборки требуются установленные инструменты Rust и Cargo.

```bash
git clone <URL_репозитория>
cd pngtuber-rust
cargo build --release
```

Готовый исполняемый файл будет находиться в директории `target/release/`. На платформе Linux для сборки также потребуются установленные пакеты `libwebkit2gtk-4.1-dev` и `libsoup-3.0-dev`.
