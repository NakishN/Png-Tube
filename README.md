# PNGTuber

Лёгкое приложение для PNG-тюберов: аватар меняет картинку, когда вы говорите, моргает и подпрыгивает в такт речи. Работает на Python + pywebview: Windows — WebView2, macOS — WKWebView, Linux — Qt WebEngine. Интерфейс — обычный HTML. Микрофон читает сам Python (sounddevice/PortAudio), поэтому браузерное разрешение на микрофон не нужно.

## Возможности

- Четыре состояния: молчит, говорит, моргает молча, моргает во время речи (моргание необязательно).
- Двухпороговый аудиорегистр (как в Veadotube mini) для четкой реакции без дрожания рта и поддержка сверхмалых задержек (до 0 мс).
- Фоновый режим для OBS Studio: окно не засыпает и не исчезает при сворачивании.
- Загрузка картинок кликом или перетаскиванием на слот, миниатюры в панели.
- Выбор микрофона, обновление списка устройств, усиление/ослабление звука (10–500%), фильтр щелчков (атака).
- Кнопка «Выключить микрофон» — звук можно полностью отключить без закрытия приложения.
- Палитра пресетов хромакея, размер аватара, отражение по горизонтали.
- Сохранение и загрузка сцены (`.pngtuber`) — настройки и картинки в одном файле.
- Настройки и картинки запоминаются между запусками в конфиг-каталоге: `~/.config/PNGTuber`, `%APPDATA%\PNGTuber`, `~/Library/Application Support/PNGTuber`.

## Требования

### Windows

- Windows 10/11 x64.
- Microsoft Edge WebView2 Runtime. В Windows 10/11 он обычно уже установлен; если приложение пишет, что WebView2 не найден — установите его: <https://go.microsoft.com/fwlink/p/?LinkId=2124703>.

### macOS

- macOS 11+.
- В релизе — arm64-сборка (Apple Silicon). На Intel Mac собирайте из исходников.
- При первом запуске macOS спросит доступ к микрофону — разрешите его в «Системные настройки → Конфиденциальность и безопасность → Микрофон».
- Если Gatekeeper блокирует неподписанное приложение:
  ```bash
  xattr -dr com.apple.quarantine /Applications/PNGTuber.app
  ```

### Linux

- x86_64, PortAudio: `sudo apt install libportaudio2` (или пакет вашего дистрибутива).
- Для Qt WebEngine могут понадобиться системные библиотеки (`libxcb-cursor0`, `libxkbcommon-x11-0`, `libnss3`, `libgbm1` и т.п.).
- Wayland: перемещение окна за пределы экрана композитором обычно запрещено, поэтому парковка в фон может не работать. В этом случае используйте видимое окно + хромакей.

## Использование

1. Скачайте архив для своей системы в разделе Releases, распакуйте его целиком в папку и запустите `PNGTuber`.
2. Откроется окно с панелью настроек (клавиша `S` показывает и скрывает её).
3. Вкладка «Аватар» — загрузите свои картинки. Начните с «Молчит»: без неё остальные состояния могут быть не видны.
4. Вкладка «Звук» — выберите микрофон и настройте чувствительность (зелёный маркер — открытие рта, оранжевый — закрытие). Микрофон запускается автоматически; кнопка «Выключить» останавливает его.
5. Сохраните сцену, чтобы не загружать картинки заново.

## OBS Studio

1. Источник «Захват окна» → окно PNGTuber.
2. Сначала скройте панель настроек клавишей `S`, иначе она попадёт в кадр.
3. Фильтры → «Хромакей». Фон по умолчанию зелёный (`#00ff00`); цвет меняется на вкладке «Экран».
4. Вместо хромакея можно запустить с флагом `--transparent` (прозрачное окно). На части систем Linux из-за этого появляются артефакты отрисовки, а захват окна с альфа-каналом поддерживается не во всех ОС/версиях OBS — по умолчанию режим выключен.
5. Чтобы убрать окно с глаз, но оставить его доступным для OBS:
   - кнопка «Скрыть окно в фон»;
   - либо включённый чекбокс «Не засыпать при сворачивании» + обычное сворачивание.
6. Вернуть окно: нажмите `S` (если окно в фокусе) или запустите PNGTuber ещё раз — второй процесс разбудит первый.

## Запуск из исходников

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

На Linux для микрофона нужна системная библиотека PortAudio (`sudo apt install libportaudio2`).

## Диагностика

- Лог приложения: `%APPDATA%\PNGTuber\pngtuber.log` (Windows), `~/.config/PNGTuber/pngtuber.log` (Linux), `~/Library/Application Support/PNGTuber/pngtuber.log` (macOS). Рядом `crash.log` — падения в нативном коде (Qt / WebView2 / PortAudio).
- В лог пишутся версия приложения, Python, pywebview, платформа, список микрофонов и JS-ошибки.
- Второй запуск не создаёт второй процесс: он находит уже работающее окно, показывает его и завершается сам.
- Настройки, картинки и сцены пишутся через уникальный временный файл и `os.replace`: обрыв процесса не оставляет «половинчатые» `settings.json` и PNG, а быстрые перетаскивания в один слот не конфликтуют.
- Импортированные картинки автоматически уменьшаются до 1000 px по длинной стороне и пересохраняются в PNG. Для панели отдельно генерируются превью 160 px, чтобы браузер не декодировал полноразмерный PNG дважды.

## Память и тесты

Приложение оптимизировано под небольшое потребление памяти:

- картинки 1000 px + отдельные превью 160 px;
- на Windows/macOS не устанавливаются PyQt6/QtWebEngine — используется родной webview;
- NumPy не нужен: аудио считается через `array`/`math`;
- на Linux остаётся Qt WebEngine, это самая тяжёлая часть (~100–150 МБ PSS).

Замер утечек:

```bash
pip install -r requirements-memory.txt
playwright install chromium
python tests/memory_probe.py --mode all --cycles 200 --json memory.json
```

Скрипт проверяет Python-core (картинки, настройки, сцены) и Chromium-фронтенд (JS heap после принудительного GC, DOM, RSS). Для Windows/Linux/macOS есть workflow `.github/workflows/memory.yml` — он запускается вручную или при изменении тестов и складывает JSON-отчёты в артефакты.

Обычные тесты:

```bash
pip install -r requirements-dev.txt
python -m pytest -q
ruff check main.py tests
node --check web/app.js
```

## Известные ограничения

- Анимированные GIF/WebP в слотах сохраняются первым кадром: PNGTuber работает с четырьмя статичными состояниями.
- На Windows используется WebView2 (Edge), на macOS — WKWebView, на Linux — Qt WebEngine, поэтому флаги Chromium задаются по-разному.
- На Wayland парковка окна за экран может не работать.
- macOS-релиз не подписан и не notarized; при блокировке используйте команду `xattr` выше.
- Intel-сборка macOS в релизе не публикуется; собирайте из исходников.

## Структура

```
main.py            окно (pywebview), хранение настроек и картинок, аудио, сцены
web/index.html     разметка
web/style.css      оформление
web/app.js         логика: аудио, состояния аватара, настройки
PNGTuber.spec      PyInstaller-сборка для Windows/Linux/macOS
tests/             pytest + memory_probe
```

Сборка исполняемого файла выполняется через GitHub Actions (`.github/workflows/release.yml`) при пуше тега `v*` или вручную.
